Codename Showstopper is now One Crest Kharghar

Updated 16 November 2026

Codename Showstopper, the luxury tower in Sector 20, Kharghar, is now called One Crest. It is the same project: same developers, same site and the same MahaRERA registration (PR1270002601519).

Other names for One Crest

Before it was called One Crest, the project was marketed as Codename Showstopper, and earlier as Codename Mansionz. Some people also call it Satyam Show Stoppers, Metro Satyam or Satyam One Crest. All these names mean the same tower in Sector 20, Kharghar (MahaRERA PR1270002601519).

What changed

  • The name: Codename Showstopper was the launch name. The developer now markets the project as One Crest.
  • New project branding, including the Stellar Lobby and Verve Clubhouse furnished with Roberto Cavalli Home Interiors.
