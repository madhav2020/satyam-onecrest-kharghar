1. **One clean, current price table**: RERA carpet + usable carpet + "from" agreement value for all 5 types + Jodi, with "price as on" date. Nobody has all of these correct together.

3. **Possession explained properly**: the RERA completion date, and the developer's target if it's different.
4. **The name story**: Codename Mansionz → Codename Showstopper → One Crest, on one page. It captures all old-name searches.
5. **Roberto Cavalli co-branding + the developer's own amenity names** (Club Verve, Verde Podium Garden, Runway pool, Stellar Lobby…). Few sites list them.
6. **All-in cost method**: rates public (stamp duty 7%, GST 5%, registration), full rupee breakdown after the form.
7. **The five type names** (Label, Luxe, Couture, Atelier, Maison En-Suite). Almost no site lists Maison En-Suite.
8. **Trust**: Reco Property + agent MahaRERA number + "authorised channel partner, not the developer's site", with "Last updated" dates.
